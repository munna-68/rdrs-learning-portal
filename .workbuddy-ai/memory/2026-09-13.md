# 2026-09-13

## Built: RDRS Learning Portal (complete)

Static Vite + React + Tailwind course platform at `~/workbuddy-ai/rdrs-learning-portal`.
Delivered from a single detailed spec. No backend, no auth — `localStorage` is the
entire persistence layer.

### Key decisions
- **Vite 5 + React 18 + Tailwind 3.4** (pinned Tailwind to v3, not v4: v4 emits
  `oklch()` colours which plain `html2canvas` cannot parse).
- **YouTube IFrame Player API** (not a plain `<iframe>`) so playback state and
  playhead are readable from JS.
- **Watch time = wall-clock accumulation, not playhead position.** A 1s poll
  measures real elapsed time and banks it only while state is `PLAYING`, capped at
  3s per tick and clamped to the video's own duration. This makes seeking forward
  worthless, which is the actual anti-cheat requirement.
- **`estimatedDuration` per module** in the config as the progress denominator
  fallback, replaced by the real duration as soon as each player loads. Keeps the
  overall bar meaningful on the first visit.
- **Sticky 80% unlock** — `completedAt` is written once and never revoked, so a
  later, more precise duration reading can't re-lock an earned certificate.
- **Certificate = off-screen mounted DOM at 1123×794 (landscape A4 @96dpi)**,
  rasterised with `html2canvas-pro` at 2× and placed full-bleed on a landscape A4
  page with `jsPDF`. Kept permanently mounted so there's no mount/capture race.
- **PDF libs are dynamic `import()`s** — main bundle 55 kB gzip, PDF chunks load
  only on click.

### Verified (46 automated checks, dev + prod builds, all pass)
Real headless-Chrome CDP harness. Highlights:
- Real YouTube playback banked **8.3s of watch time in ~9s** — confirms tracking
  works and that StrictMode does not double-count.
- Downloaded PDF: 161 kB, `%PDF-` header, **1 page, MediaBox 841.89×595.28pt**
  (landscape A4), named `Jane-Doe-Certificate.pdf`.
- Certificate DOM contains brand, course title, learner name, date, certifying line.
- Reset control clears all 4 keys and returns to welcome.
- No horizontal overflow at 390/375/360/430 px widths.

### Gotchas hit (now recorded in the `sandboxed-web-app-build-qa` skill)
- `run_in_background` dev servers still get reaped — start Vite **in-process**
  inside the QA script via its Node API.
- Tailwind resolves `tailwind.config.js` from **process CWD**, not Vite `root`.
  Running the harness from `/tmp` silently produced broken CSS.
- `Page.navigate` to the current URL is a no-op — use `Page.reload`.
- `innerText` reflects `text-transform: uppercase`, and JSX `&rsquo;` is U+2019 —
  both broke naive assertions against working code.
